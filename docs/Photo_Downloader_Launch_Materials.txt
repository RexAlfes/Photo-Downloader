# Photo Downloader v0.1.0-alpha
A lightning-fast, native desktop application for automated media ingestion, renaming, and organization.

Photo Downloader is an open-source tool built from the ground up for speed, reliability, and local data control. Developed natively in Lazarus / Free Pascal, it features a zero-bloat, high-performance engine that automates the tedious parts of your photography workflow without tracking, cloud dependencies, or subscription fees. 

It serves as a modern, GPL-licensed alternative to paid, subscription-based and pay-for-upgrade ingestion software.

Key Features (Available in Build 37)
--------------------------------------
* High-Performance Scanning: Fast recursive scanning of source folders, local drives, or network locations, with an option to isolate just the DCIM directory.
* Extensive Format Support: Ingestion, thumbnails and camera data for JPEG, PNG, BMP, TIFF, DNG and RAW files with embedded previews (NEF, NRW, CR2, CR3, CRW, ARW and others). HEIC (camera data, renaming and picture previews all work out of the box). Video and audio files (MP4, MOV, LRV, MP3) are in development.
* Advanced Token-Based Renaming: Dynamically rename files using a highly customizable token engine based on precise EXIF temporal data, camera models, and sequential counters.
* Intelligent Status Detection: Automatically identifies and labels files on import as "New file", "Already downloaded", "Name clash", or "Duplicate file" (analyzing size, time, and camera metadata to protect your archives).
* Automated Organization: Builds structured "Date - Job Code" directory trees automatically.
* Smart Metadata & Sidecars: Writes author and copyright directly to empty fields in JPEG EXIF data on download, and automatically generates XMP sidecars from IPTC data.
* Removable Drive Integration: Windows auto-detection for connected card readers with a built-in PowerShell-driven safe ejection routine.
* Integrated Workflow: Built-in thumbnail viewer grid (with scrolling-throttled memory management), a 2/3 window quick image viewer, and custom external tool launcher integration.

Tech Stack & Architecture
-------------------------
* Framework/Compiler: Lazarus 4.8 / Free Pascal Compiler (FPC) 3.2.2
* Platform: 64-bit program. 32-bit builds are not provided at this time; if you need one, request it through the GitHub testing process (open an issue) or the online testing form.
* Configuration: Portable configuration parsing via PhotoDownloader.ini and a local user profile system

Title: [Windows Alpha] Looking for testers for a free, open-source, native Lazarus alternative to paid photo ingest software

Hi everyone,

Like a lot of high-volume photographers, I’ve been frustrated by the lack of fast, modern, and completely local media ingestion tools. I miss old-school, lightweight desktop utilities that just worked instantly without needing an internet connection or a monthly subscription fee. 

To solve this, I've spent the last few months building Photo Downloader—a native desktop ingestion and renaming tool built using Lazarus 4.8 and FPC 3.2.2. It is fully licensed under the GNU GPL v3. 

It is currently in Alpha (Build 37), and I’m looking for photographers shooting various camera systems to put the file-parsing engine through its paces.

What it does right now (Build 37):
* Lightning-Fast Card Scanning: Point it at a card reader or folder tree (or let it auto-detect a Windows DCIM drive). It handles everything from standard JPEGs to complex RAWs (CR3, ARW, NEF, etc.). HEIC previews work out of the box; video and audio support are in development.
* Advanced Token Renaming: Uses dynamic metadata tokens to reconstruct file names on the fly based on shot time, camera body mapping, job codes, and sequence counters.
* Smart Duplication Handling: Before copying, it flags items as New, Already Downloaded, Name Clash, or Duplicate based on a matrix of file size, timestamp, and camera signatures.
* Metadata Injector & Sidecars: Automatically injects author/copyright data into blank JPEG EXIF fields and generates XMP sidecars during ingestion.
* Fast Previews: Leverages the largest embedded JPEGs inside RAW files to populate a fast-scrolling thumbnail grid. 
* Safe Dismounting: Includes a built-in card ejection utility powered by PowerShell.

What I need help testing during Alpha:
Because it's a native Pascal build, it's incredibly light and fast, but I need diverse real-world file samples to test edge cases:
1. Nikon Users: Testing embedded preview decoding on a wide range of native .NEF files.
2. Pathing Limits: Testing performance over complex network topologies (UNC paths like \\NAS\Photos).
3. UI Feedback: Forms are currently completely built in code (converting to .LFM is on the immediate roadmap), so I'd love feedback on layout scaling.

If you want to escape subscription-based workflows and play with a highly portable, ultra-fast downloader utility, please check out the repository!
