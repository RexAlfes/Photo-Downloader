Take Back Control of Your Workflow

Stop paying monthly subscriptions for heavy cloud applications. Photo Downloader is a completely local, high-performance desktop ingest tool licensed under the GNU GPL v3. It handles lightning-fast card imports, automatic file renaming from custom tokens, and organized directory tree generation.

Current Features (Build 12)

⚡ Native Performance

Compiled natively via Lazarus 4.8 / FPC 3.2.2. Zero bloated background web frameworks, minimal dependencies, and rapid folder execution.

🏷️ Token Renaming

Dynamically rename files using EXIF time/date, camera signatures, sequential counters, and project tracking job codes.

🔍 Intelligent De-duplication

Detects duplicate source images accurately by cross-checking matching file sizes, modification stamps, and camera data before ingestion.

📦 Professional Outputs

Automatically generates XMP sidecars from IPTC inputs and injects copyright metadata smoothly into empty JPEG fields.

How to Help Test
