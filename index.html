Take Back Control of Your Workflow

Photo Downloader is a local desktop ingest tool licensed under the GNU GPL v3 or later. It scans a memory card or folder, shows thumbnails (including RAW previews), renames files from templates built from EXIF data and your own job codes, and copies them into an organised folder tree. Nothing is uploaded anywhere and no account is needed.

Features

⚡ Native Desktop App

Compiled with Lazarus 4.8 / Free Pascal 3.2.2 into a single Windows executable. No runtime, no installer framework and no background services.

🏷️ Token Renaming

Name files and folders from the capture date and time, camera model and serial, original name, sequence counters and per-day job codes.

🔍 Duplicate & Clash Checks

Flags images that are already downloaded, duplicate copies (same size, capture time and camera) and name clashes, and tells you why a file is flagged.

📷 JPEG, RAW, TIFF & DNG

Thumbnails and a viewer for JPEG, PNG, BMP, TIFF and DNG, and for the embedded previews in NEF, NRW, CR2, CRW, ARW, SR2, SRF and other RAW files.

📦 Metadata Output

Writes XMP sidecars from your IPTC/XMP details and can add author and copyright to JPEG EXIF fields that are empty. Existing values are never overwritten.

🛡️ Careful Deleting

Files are only deleted from the card after they have been downloaded and the copy is confirmed to exist in the destination.

Known Limitations

  • Windows is the primary platform. Card-reader detection, eject and the single-instance option are Windows only.
  • Direct USB camera (PTP/MTP) download, GPS geotagging, MD5-verified copy and lossless auto-rotate are not implemented yet.
  • Compressed (LZW/Deflate) TIFF files without a JPEG preview show a placeholder instead of a thumbnail.

How to Help Test

Feedback from real photography workflows is what this project needs most. If you find an EXIF, thumbnail or naming problem, open an issue and describe the camera and file type. For thumbnail problems, attach thumbnail.log from the Photo Downloader folder inside your local application data folder (%LOCALAPPDATA%).
