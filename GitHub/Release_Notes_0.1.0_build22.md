## Photo Downloader 0.1.0 – Alpha build 22

> **Alpha software.** Keep your original files until you have checked the copies. Windows is the primary platform.

### What's new
- **Startup window width.** The window is measured after it opens, so the vertical scroll bar no longer takes space from the thumbnail cards. It opens with 3 large-thumbnail columns, or 2 columns when 3 would make the window wider than 66% of the desktop.
- **Settings file documented.** The location and every key of `PhotoDownloader.ini` are described in the README and in `docs/Settings_File.md`.
- **README.** The HEIC add-on steps are now listed separately for the XelImageFormats package and the HeifImage unit.
- Spelling: "License" throughout.
- Lossless auto-rotate, upright previews, Canon CR3 and optional HEIC previews from earlier builds carry over.

### In development
Video and audio files.

### Known limitations
- Card-reader detection, eject and single-instance handling are Windows only.
- Not yet implemented: USB camera download (PTP/MTP), GPS geotagging, MD5-verified copy, watch mode, download history.
