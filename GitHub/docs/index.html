Take Back Control of Your Workflow

Photo Downloader is a local desktop ingest tool licensed under the GNU GPL v3 or later. It scans a memory card or folder, shows thumbnails (including RAW previews), renames files from templates built from EXIF data and your own job codes, and copies them into an organized folder tree. Nothing is uploaded anywhere and no account is needed.

Features

⚡ Native Desktop App

Compiled with Lazarus 4.8 / Free Pascal 3.2.2 into a single executable for Windows 64-bit or Linux 64-bit. No runtime, no installer framework and no background services. Only reading Lightroom catalogs uses an outside library: SQLite, which is part of Windows 10 and 11 (winsqlite3.dll) and of nearly every Linux system.

🏷️ Token Renaming

Name files and folders from the capture date and time, camera model and serial, original name, file extension, sequence counters and per-day job codes. Every token works in folder and file names alike, and plug-in libraries can add their own tokens.

🔍 Duplicate & Clash Checks

Flags images that are already downloaded, duplicate copies (same size, capture time and camera) and name clashes, and tells you why a file is flagged.

📷 JPEG, RAW, TIFF & DNG

Thumbnails and a viewer for JPEG, PNG, BMP, GIF, TIFF, DNG, WebP, HEIC and AVIF, and for the embedded previews in NEF, NRW, CR2, CRW, ARW, SR2, SRF and other RAW files. Sortable list view with column headings, and thumbnail sizes from small to large, or fitted to the window width (Ctrl + mouse wheel resizes). Adobe Lightroom preview files (.lrprev) can be listed and viewed. MP4, MOV and LRV video and MP3 audio files are listed too, with video frames as thumbnails where the system can make them, and they play in your default player on double-click.

📦 Metadata Output

Writes XMP sidecars from your IPTC/XMP details and can add author and copyright to JPEG EXIF fields that are empty. Existing values are never overwritten.

🛡️ Careful Deleting

Files are only deleted from the card after they have been downloaded and the copy is confirmed to exist in the destination. Deleted files go to the Recycle Bin or system trash, or to a hidden trash folder on the card that you can view and empty from the File menu.

✅ Verified Copy & Backup

Every copy is read back and its checksum compared with the original; a bad copy is deleted and retried. An optional second copy can go to a backup folder. Cancel mid-file and resume later.

🔄 Lossless Auto-Rotate

Portrait JPEGs, including progressive ones, are turned upright from their EXIF orientation without recompressing, so there is no quality loss.

Known Limitations

  • Windows is the primary platform. The Linux build has been tested on Linux Mint 22.3 (GTK 2 widgetset); other distributions and the Qt widgetset are untested.
  • The single-instance option is Windows only.
  • Direct USB camera (PTP/MTP) download, GPS geotagging, a download history and RAW+JPEG pairing are not implemented yet.
  • Lightroom previews (.lrprev) are small (at most 256 px); they can be downloaded as .jpg, or as both .lrprev and .jpg. Their file name, date and camera come from the Lightroom catalog when it is found, which needs the SQLite library (built into Windows 10 and 11; on older Windows place the 64-bit sqlite3.dll next to the program).
  • Video thumbnails depend on the system (Windows Shell codecs; ffmpegthumbnailer or ffmpeg on Linux). MP3 files show a default tile without cover art or length.

Windows says “Unknown publisher”

Photo Downloader is free and open source, and its program file is not code-signed, so Windows may show Windows protected your PC (SmartScreen) with Publisher: Unknown publisher the first time you run it. This does not mean the file is damaged. Download only from the releases page, click More info, then Run anyway. If there is no such button, right-click the downloaded file, choose Properties, tick Unblock and click OK. Your browser may also ask you to Keep the file. With Windows 11 Smart App Control on, unsigned programs are blocked; the User Manual explains the options.

Running on Linux

Download the Linux 64-bit file from the release, unpack it and run PhotoDownloader. You need the GTK libraries that come with most desktops, plus udisks2 and gio (package libglib2.0-bin) for card eject and the system trash, and xdg-open for “show in folder”. Settings are kept in ~/.config/PhotoDownloader/ and the thumbnail cache in ~/.cache/PhotoDownloader/. To build it yourself, see docs/Linux_Build.md in the repository.

How to Help Test

Feedback from real photography workflows is what this project needs most. If you find an EXIF, thumbnail or naming problem, open an issue and describe the camera and file type. For thumbnail problems, attach thumbnail.log: use Help > Save log file… in the program, or find it in the Photo Downloader folder inside %LOCALAPPDATA% on Windows or ~/.config/PhotoDownloader/ on Linux.
