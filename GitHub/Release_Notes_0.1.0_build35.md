## Photo Downloader 0.1.0 – Alpha build 35

> **Alpha software.** Keep your original files until you have checked the copies. Windows is the primary platform.

### What's new
- **Destination change rescans.** When you change the destination folder or file name pattern in Preferences, the loaded files are checked again against the new destination, so Downloaded, name-clash and duplicate marks are up to date straight away.
- Build 34 changes carry over: Help > Logging, Help > Save log file..., video/audio/THM off by default, faster HEIC/AVIF thumbnails with a disk cache.

### In development
Video and audio files.

### Known limitations
- Card-reader detection, eject and single-instance handling are Windows only.
- Not yet implemented: USB camera download (PTP/MTP), GPS geotagging, MD5-verified copy, watch mode, download history.
