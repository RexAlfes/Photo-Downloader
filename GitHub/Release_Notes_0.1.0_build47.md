## Photo Downloader 0.1.0 – Alpha build 47

> **Alpha software.** Keep your original files until you have checked the copies. Windows is the primary platform.

### What's new
- The default name of the hidden trash folder used by safe delete is now `$trash.bin` (lower case). A name saved earlier in your settings is kept; change it in Preferences > Automation.
- The safe delete confirmation text is split over three lines so it fits the dialog.
- Tested and working: safe delete, the trash folder name setting, blank job code, start-up profile prompt with Default.
- Earlier changes carry over: configurable trash folder, View Trash / Empty Trash, progressive JPEG auto-rotate, sortable list view, verified copy and backup.

### In development
Video and audio files.

### Known limitations
- Card-reader detection, eject and single-instance handling are Windows only.
- Not yet implemented: USB camera download (PTP/MTP), GPS geotagging, watch mode, download history.
- Progressive JPEG rotation and Empty Trash / View Trash need more testing.
