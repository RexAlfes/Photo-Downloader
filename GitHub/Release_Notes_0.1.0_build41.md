## Photo Downloader 0.1.0 – Alpha build 41

> **Alpha software.** Keep your original files until you have checked the copies. Windows is the primary platform.

### What's new
- **TIFF viewer fix.** Double-clicking a palette, compressed or 1-bit TIFF opened a black window ("no preview available"). The viewer now uses the same TIFF reader as the thumbnails.
- Build 40 changes carry over: thumbnails for LZW, PackBits, Deflate and fax-compressed TIFF scans, large-folder fix, verified copy, backup destination.

### In development
Video and audio files.

### Known limitations
- Card-reader detection, eject and single-instance handling are Windows only.
- Not yet implemented: USB camera download (PTP/MTP), GPS geotagging, MD5-verified copy, watch mode, download history.
