Description (223 chars):
Free, open source Windows photo ingest tool: copies images from memory cards, renames with EXIF and job-code tokens, flags duplicates and name clashes, previews RAW/TIFF/DNG, writes XMP sidecars. Built with Lazarus. GPL v3.
