## Photo Downloader 0.1.0 – Alpha build 45

> **Alpha software.** Keep your original files until you have checked the copies. Windows is the primary platform.

### What's new
- **Trash folder name.** The hidden folder safe delete uses on cards, USB and network drives is now `$Trash.bin`. Change the name in Preferences > Automation.
- **File > View Trash** opens the trash folder of the source drive; **File > Empty Trash...** erases its contents after a confirmation showing the file count and size.
- List view column headings and sorting were tested and work.
- Build 43 and 44 changes carry over: safe delete, auto-rotate of progressive JPEGs, sortable list view.

### In development
Video and audio files.

### Known limitations
- Card-reader detection, eject and single-instance handling are Windows only.
- Not yet implemented: USB camera download (PTP/MTP), GPS geotagging, watch mode, download history.
- Safe delete, the trash menu items and progressive rotation are new and need testing.
