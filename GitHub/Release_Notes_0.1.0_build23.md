## Photo Downloader 0.1.0 – Alpha build 23

> **Alpha software.** Keep your original files until you have checked the copies. Windows is the primary platform.

### What's new
- **Start-up width for small thumbnails.** In small-thumbnail view the window opens with 4 columns, or 2 columns when 4 would make the window wider than 66% of the desktop (the same rule as large thumbnails with 3 columns).
- Compiler hints removed in the single-instance and rotation code.
- Earlier builds' changes carry over: lossless auto-rotate, upright previews, Canon CR3, optional HEIC previews, settings file documentation.

### In development
Video and audio files.

### Known limitations
- Card-reader detection, eject and single-instance handling are Windows only.
- Not yet implemented: USB camera download (PTP/MTP), GPS geotagging, MD5-verified copy, watch mode, download history.
